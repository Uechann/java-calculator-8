# java-calculator-precourse

## 요구사항

- 쉼표(,), 콜론(:)을 구분자로 가지는 문자열을 전달할 경우 구분자를 기준으로 분리한 각 숫자의 합을 반환
  예 : 0, "1,2" => 3
  예 : "1,2,3" => 6
  예 : "1,2:3" => 6

- 앞의 기본 구분자 외의 커스텀 구분자를 지정할 수 있다.
  커스텀 구분자는 문자열 앞부분의 "//"와 "\n" 사이에 위치하는 문자를 커스텀 구분자로 사용한다.
  예 : "//;\n1;2;3"
  이렇게 입력하면 커스텀 구분자는 세미콜론(;)이 되고, 결과 값은 6이 된다.

- 사용자가 잘못 입력할 경우 `IllegalArgumentException`을 발생 시키고 애플리케이션은 종료된다.

## 기능 목록

### 기능 1. 입력/출력 뷰 구현
- **기능 설명**: 사용자로부터 문자열을 입력받고 계산 결과를 출력하는 View 계층을 구현한다.
- **세부 구현**:
  - `InputView`: 사용자에게 입력 안내 메시지를 출력하고 문자열을 입력받는다.
  - `OutputView`: 계산된 결과를 화면에 출력한다.

### 기능 2. 기본 구분자를 이용한 숫자 추출 기능
- **기능 설명**: 쉼표(`,`)와 콜론(`:`)을 구분자로 사용하여 문자열에서 숫자를 추출한다.
- **세부 구현**:
  - 입력 문자열을 `,` 또는 `:`로 분리
  - 분리된 각 부분을 정수로 변환하여 `Number` 엔티티에 저장
  - 빈 문자열("")이 입력되면 빈 리스트 반환
- **예외 처리**: 정규식 패턴에 맞지 않으면 `IllegalArgumentException` 발생
- **테스트 케이스**:
  - `"1,2,3"` → `[1, 2, 3]`
  - `"1:2:3"` → `[1, 2, 3]`
  - `"1,2:3"` → `[1, 2, 3]`
  - `""` → `[]`

### 기능 3. 커스텀 구분자를 이용한 숫자 추출 기능
- **기능 설명**: 사용자가 지정한 커스텀 구분자를 이용하여 문자열에서 숫자를 추출한다.
- **세부 구현**:
  - 입력이 `//`로 시작하고 `\n`을 포함하는지 확인
  - `//`와 `\n` 사이의 문자를 커스텀 구분자로 추출
  - `\n` 이후의 문자열을 커스텀 구분자로 분리
  - 분리된 각 부분을 정수로 변환하여 `Number` 엔티티에 저장
- **예외 처리**: 정규식 패턴에 맞지 않으면 `IllegalArgumentException` 발생
- **테스트 케이스**:
  - `"//;\n1;2;3"` → 구분자: `;`, 결과: `[1, 2, 3]`
  - `"//|\n4|5|6"` → 구분자: `|`, 결과: `[4, 5, 6]`

### 기능 4. 추출한 숫자들을 더하는 계산기 기능
- **기능 설명**: 추출된 숫자들의 합을 계산한다.
- **세부 구현**:
  - `Number` 엔티티에 저장된 모든 숫자를 순회하며 합산
- **예외 처리**: 없음
- **테스트 케이스**:
  - `[1, 2, 3]` → `6`
  - `[4, 5, 6]` → `15`
  - `[]` → `0`

### 기능 5. 사용자 입력 검증 기능
- **기능 설명**: 정규식을 이용하여 사용자의 입력이 올바른 형식인지 검증한다.
- **세부 구현**:
  - `RegularExpressionService`에서 구분자 기반 정규식 패턴 생성
  - 패턴: `^(?:\d+(?:(구분자들)\d+)*)?$`
  - 입력 문자열이 `숫자 + 구분자 + 숫자` 패턴에 맞는지 확인
  - 검증 실패 시 `IllegalArgumentException` 발생
- **예외 처리**:
  - 연속된 구분자: `"1,,2"` → 예외 발생
  - 구분자로 시작: `",1,2"` → 예외 발생
  - 구분자로 끝남: `"1,2,"` → 예외 발생
  - 문자 포함: `"1,a,2"` → 예외 발생

### 기능 6. 전체 흐름 통합
- **기능 설명**: MVC 패턴에 따라 View-Controller-Service-Entity 간의 흐름을 통합한다.
- **세부 구현**:
  - `CalculatorController`에서 전체 흐름 제어
